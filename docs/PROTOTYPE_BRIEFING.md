# KSP DRISTI - Prototype Briefing Document

This document provides a comprehensive overview and executive briefing of the **KSP DRISTI** (Conversational Intelligence & Crime Analytics Platform) prototype. It outlines what has been built, the underlying dataset, the core features, the technology stack, and its real-world impact.

---

## 🎯 Executive Summary
**KSP DRISTI** is a production-ready, full-stack crime intelligence command center designed for law enforcement agencies. The solution bridges the gap between massive raw datasets and actionable field intelligence. It consists of:
1. **Next.js Web Command Dashboard**: A desktop command center for high-level monitoring, analytics, and dispatch.
2. **Flutter Mobile Companion App**: An on-field utility for patrolling officers and investigators.

Both interfaces query a unified, relational database seeded directly from a 1.6 Million row Karnataka State Police (KSP) dataset.

---

## 📂 The Data Foundation
* **Dataset**: Real 1.6 Million row KSP CSV records.
* **Ingestion Pipeline (`csv_parser.py`)**: Samples 1,200 diverse, highly populated records, resolves geographical district coordinate offsets, maps relational keys, and writes them into structured JSON collection tables.
* **Relational Tables**: `District`, `Unit` (Police Stations), `CaseMaster` (FIRs), `ComplainantDetails`, `Victim`, `Accused`, `ArrestSurrender`, `ActSectionAssociation` (IPC/BNS), and `FinancialTransactions` (Mule Accounts).

## 🚀 Core Features Implemented

### 1. Conversational Crime Intelligence (Voice + text)
* **What it is**: A natural language chatbot supporting voice input (using the Web Speech API) in **English (`en-IN`)** and **Kannada (`kn-IN`)**.
* **How it works**: Preprocesses inputs (resolving Hinglish, shorthand, and typos) and prompts the LLM to write exact SQL (ZCQL) filters to fetch matching cases.
* **Citations**: Returns briefings with clickable evidence references (`CaseMasterID`, `AccusedMasterID`) mapping back to the database.

### 2. Spatial Patrolling & Heatmaps (Leaflet Map)
* **What it is**: An interactive Leaflet map canvas plotting crime hotspots by district.
* **Beat Patrol Route Generator**: A supervisor selects a sector, the system clusters crime coordinates (K-Means), and runs a Travelling Salesman Problem (TSP) routing algorithm to generate an optimized route polyline synced directly to field officers.

### 3. Criminal Linkages Network (SVG Canvas)
* **What it is**: An interactive visualizer showing accomplice relationships and financial money laundering paths.
* **Transaction Tracing**: Displays transaction connections between suspect accounts and destination bank accounts (line thickness is proportional to the money transferred).

### 4. Habitual Offender Recidivism Gauge
* **What it is**: An algorithmic risk profiler mapping the probability (0-100%) of an offender re-offending.
* **Parameters**: Evaluates previous arrest count, severity of offenses, and timelines to output low, medium, or high-risk levels.

### 5. Explainable AI Console (ZCQL SQL Trace)
* **What it is**: A terminal drawer showing transparency.
* **Accountability**: Prints the exact ZCQL SQL command generated by the LLM and executed against the database, ensuring analysts can verify the filters.

## 🛠️ Technology Stack

| Component / Layer | Technology Chosen | Purpose & Advantage |
| :--- | :--- | :--- |
| **Web Dashboard** | **Next.js 14+ (React)** | Compiles fast dashboard states, layout routes, and handles API requests. |
| **Mobile App** | **Flutter SDK (Dart)** | Unified Android/iOS companion application for field patrolling. |
| **AI Orchestrator**| **Groq Llama 3.3 (70B)** | High-speed LLM inference (~50ms latency) translating inputs and compiling briefings. |
| **Database Parser**| **ZCQL Helper Engine** | Custom AST interpreter parsing SQL `SELECT`, `JOIN`, and `LIKE` queries locally on JSON. |
| **Mapping Engine** | **Leaflet / React Leaflet** | Renders geospatial hotspots and beat patrol path polylines. |
| **PDF Dossier** | **jsPDF Library** | Generates detailed investigation dossiers containing transaction maps and arrest logs. |
| **Voice Processing**| **Web Speech API** | Native, serverless speech recognition without external subscription fees. |

## 👥 Role-Based Capabilities & Impact

1. **👮 Investigator**: Drafts digital FIRs, conducts voice lookups on the field, views suggested modern BNS legal codes, and exports multi-page PDF dossiers.
2. **🧠 Analyst**: Inspects money flow streams, highlights suspect linkages, and gauges offender recidivism risk profiles.
3. **🛰️ Supervisor**: Generates optimized beat patrol paths and sends them directly to mobile terminals.
4. **📈 Policymaker**: Identifies state-wide demographic crime distributions to allocate resources.
